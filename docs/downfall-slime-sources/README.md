# Downfall Slime Boss visual references

Captured from Jorbs' PC *Downfall* Slime Boss run:
<https://www.youtube.com/watch?v=WY-sozrZgBU&t=3017s>.

- `pc-battlefield-layout.jpg` records the boss/minion ground-slot layout.
- `pc-command-*` records a minion Command attack.
- `pc-spawn-*` records the boss creating minions.
- `slime-card-art-reference.jpg` contains the thirteen board-game Slime identities.
- `generated-base-contact-sheet.jpg` records the transparent base-asset batch generated from those cards and the game's existing Slime cutouts with the direct OpenAI Images API (`gpt-image-2`).
- `generated-animation-contact-sheet.jpg` records all thirteen generated Command sheets and the Slime Boss minion-spawn sheet, in filename order from left to right and top to bottom.

The runtime exports are optimized WebPs under `public/assets/combat/slimes/`.
