# Kratos card and menu art

Generated with `gpt-image-2.5-sunburst`, high quality, using the bundled imagegen CLI. Every card prompt explicitly requests Greek-era God of War 1, 2 and 3 subjects and supplies the committed Cleave and Shrug It Off illustrations as the style authority, plus the approved Greek Kratos idle source for identity. Four independent paintings were generated per sheet. The 64 unique illustrations are shared by base and upgraded faces; live definitions supply each face's name, cost, type and complete rules.

`plan.json` records sheet order; `prompts/` preserves the actual generation prompts. `manifest.json` identifies each selected source, quadrant, prompt, supplied reference and output by SHA-256. Sources are lossless WebP copies of the generated PNGs, with native alpha preserved for the relic. Re-export with `python3 scripts/art/export-kratos.py` (Pillow required); this makes no API calls. Card exports are 748×420, at most 40 KiB each.

The art audit replaced Golden Fleece's draft lion ornament with ram-themed shoulder/arm armor and Cronos' Rage's draft time symbol with blue electrical orbs. Head of Helios and Head of Euryale were also regenerated as recognizable heads instead of symbolic masks. Greek-era subject references: [Golden Fleece](https://godofwar.fandom.com/wiki/Golden_Fleece), [Cronos' Rage](https://godofwar.fandom.com/wiki/Cronos%27_Rage). The close-up was also regenerated to align the eye/scalp tattoo with the left shoulder tattoo. All four selected card replacement prompts are preserved separately; their earlier sheet panels are unused.

Ashes of Sparta uses its original icon and a native rules face. The close-up is 256×384, with the head and shoulder tattoos checked against the approved idle/wallpaper identity; the wallpaper is a 1536×864 top-aligned crop of the model's 1536×1024 output. The wallpaper prompt requested 4K initially, but the CLI rejected that size before an API call; the successful request used the supported 1536×1024 size. No upscaling is used. These use the existing `portrait-kratos.png` and `character-kratos-wallpaper.webp` menu conventions. The shared `menu/compendium-icons/kratos.webp` emblem supplies the standard compendium, leaderboard and stats icon path at 256×256 with native alpha. Kratos is released in the public roster and online rooms. His portrait, wallpaper, shared icon, relic and 64-card pool are available through their production menu and library paths.

Validation: the focused Kratos card-art browser audit renders all 128 production card faces and the starter relic on desktop and horizontal phones in Chromium and WebKit, checking decoded art, exact data text, upgrade cost/type, visible keyword emphasis and text fit. Existing card-rendering checks cover shared mounted-card updates; gameplay and asset verifiers cover Kratos mechanics/release gating and bundled inventories. Browser screenshots and per-face audit reports are saved locally under `artifacts/kratos-card-art/`.
